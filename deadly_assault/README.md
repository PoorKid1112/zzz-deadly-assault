# 危局强袭战 (Deadly Assault)

《绝区零》危局强袭战（试炼模式）全流程自动化挑战插件，遵循 OneDragon 第三方插件规范开发。

> 💡 若希望在同一天一条龙中把「生成算队」前置到日常最开头执行，可搭配使用前置插件：[危局强袭战-预处理 (`deadly_assault_prepare`)](https://github.com/PoorKid1112/zzz-deadly-assault-prepare)；或者直接在插件设置中开启「分天运行模式」由本插件单插件分两天完成。

---

## 核心功能

1. **入场与主界面预检** (Step 1 - Step 6)：
   - 从大世界或快捷手册自动导航进入「快捷手册 - 作战 -> 危局强袭战（试炼）」并确认传送。
   - 进入主界面后双帧扫描下方 3 个首领槽位：若均无 `EMPTY` 且已有成绩，直接跳过配队与战斗进入领奖/结束。

2. **智能配队推荐与免等待跳过** (Step 6 - Step 12)：
   - 打开「配队指引」，自动关闭可能出现的「规则说明」弹窗并切换到「智能推荐」页面。
   - **Step 9 自动判断**：在「智能推荐」页面检测「全部应用-区域」，**只要检测到已存在「全部应用」按钮，直接跳过 Step 9 生成等待，直接进入 Step 10**；仅当尚无任何「全部应用」按钮时，才点击「生成更多」并等待验算结果。
   - 优先点击最下方「全部应用」按钮，条件确认底部水平线区域的「阵容覆盖 -> 确认」，随后返回主界面。

3. **分天运行模式 (`two_day_mode`，默认关闭)**：
   - **第 1 次运行（第 1 天）**：按 `prepare` 规则执行（Step 1-9 点击「生成更多」触发算队后**不等待** -> Step 12 返回主界面 -> Step 29 返回大世界），当天标记已完成以免重复运行。
   - **第 2 次运行（第 2 天）**：跨过凌晨 04:00 进入第 2 天后（无论是否跨过第 1 周式舆周五），执行这一次完整挑战并领奖（Step 9 检测到「全部应用」即直接应用配队）；通关后第 3 天起整个 14 天周期均自动跳过，直到第 2 个周五 04:00 危局刷新自动彻底重置。（仅当第 2 天当天未打开脚本或战斗中途失败时，才会在后续同周期首次运行补完这一次战斗。）

4. **三首领挑战与荣誉酬赏** (Step 13 - Step 29)：
   - 从左至右优先点击未挑战的 `EMPTY` 槽位（排除邦布图标 `0` 噪点干扰），兼容「下一步 / 开始挑战」OR 分支与多轮「是否确认出战？」弹窗。
   - 进战按住 `W` 前进并动态检测右上角 Boss 血条（绿色像素或数字 `29`），出现即停并运行自动战斗。
   - 全部首领完成后领取左下角「荣誉酬赏」并确认奖励（若已领光则自动关闭奖励窗），返回大世界结束。

## 插件配置项（可在客户端设置页调整）

| 配置项 | 类型 | 默认值 | 说明 |
| :--- | :---: | :---: | :--- |
| `two_day_mode` | `bool` | `False` | **分天运行模式**（默认关闭）：开启后第 1 天仅触发预处理后返回，第 2 天直接打完并结算 |
| `auto_team` | `bool` | `True` | 是否在挑战前自动执行智能推荐配队（步骤 6-12） |
| `wait_generate_seconds` | `int` | `300` | 仅当无「全部应用」按钮时，点击生成更多后的最大等待时间（秒） |
| `walk_duration` | `float` | `5.0` | 进入战斗后向前移动的最大时间（秒，检测到 Boss 血条即提前停止） |
| `claim_rewards` | `bool` | `True` | 3 关挑战完成后是否领取荣誉酬赏（步骤 26-28） |
| `auto_battle_config` | `str` | `""` | 指定自动战斗策略名称，留空则跟随全局战斗助手配置 |
| `cycle_anchor_dt` | `str` | `"20261120"` | 双周周五刷新基准日（`yyyyMMdd`，默认对应周五 04:00 刷新锚点） |

## 目录结构

```text
├── __init__.py               # Python 包标识
├── const.py                  # APP_ID, APP_NAME, PRIORITY=1220 等常量
├── factory.py                # 应用工厂 (DeadlyAssaultFactory)
├── config.py                 # 应用配置 (DeadlyAssaultConfig)
├── run_record.py             # 14 天双周周期与分天运行状态机
├── app_setting.py            # 设置入口 (DeadlyAssaultAppSetting)
├── setting_interface.py      # 客户端设置界面 (DeadlyAssaultSettingInterface)
├── screens.py                # 画面定义加载与校验
├── app.py                    # 状态机主逻辑 (DeadlyAssaultApp)
├── plugin.json               # 插件市场元数据清单
├── README.md                 # 中文说明文档
├── screen_info/              # 画面识别区域定义
└── assets/
    └── cover.webp            # WebP 封面
```
