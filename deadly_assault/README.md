# 危局强袭战 (Deadly Assault)

《绝区零》危局强袭战（试炼模式）自动化挑战插件，遵循 OneDragon 插件规范开发。

## 功能介绍

本插件实现了危局强袭战的完整自动化流程，覆盖所有操作步骤：

1. **入场与选关** (Step 1 - Step 5)：
   - 从大世界（按住 Alt 点击 F2 快捷手册）或当前界面自动导航进入「快捷手册 - 作战」。
   - 点击左侧「危局强袭战」，选择「试炼」模式卡片中的「前往」，并点击弹窗中的「确认」立即传送。

2. **智能配队推荐** (Step 6 - Step 12)：
   - 自动进入危局强袭战主界面后检测并点击「配队指引」。
   - 检查并自动关闭可能出现的规则说明弹窗。
   - 切换到「智能推荐」页面，点击「生成更多」并等待验算完成（默认等待并检测新生成的配队）。
   - 检测目标区域内的「全部应用」按钮（若有多个生成结果则优先应用最下方）。
   - 条件检测并确认「阵容覆盖」对话框，点击左上角红色返回按键返回危局强袭战主界面。

3. **三首领挑战循环** (Step 13 - Step 25)：
   - 检测下方 3 个槽位的 `EMPTY` 状态与精确坐标，优先选择最左侧未完成槽位（左 -> 中 -> 右优先级依次挑战）。
   - 点击右下角「选定敌方」进入关卡详情，支持「下一步」与「开始挑战」双分支匹配。
   - 条件检测出战锁定确认弹窗（「是否确认出战？」），并完成通用出战确认。
   - 进战加载完毕后，**按住 W 键向前移动，同时动态检测右上角 Boss 血条（荧光绿像素 / 数字 29）**，血条一出现立即停止 W 并启动自动战斗。
   - 战斗胜利/结算时检测右下角「退出」按钮，自动停止战斗并点击退出返回主界面。
   - 循环完成左侧、中间、右侧全部 3 个首领关卡。

4. **荣誉酬赏领取** (Step 26 - Step 29)：
   - 3 个首领挑战完成后，在左下角检测「荣誉酬赏」文字，精准点击其上方宝箱图标。
   - 弹出挑战奖励窗口后点击「全部领取」。
   - 确认获得的菲林、业绩、丁尼等奖励。
   - 点击左上角返回并退回大世界，任务圆满结束。

## 插件规范与设计特色

- **零盲点点击**：严格遵循 OneDragon 插件规范，所有交互动作均在目标区域识别并验证符合特征/文本（OCR 或特征匹配）后再触发点击，杜绝任何固定坐标盲点。
- **超轻量素材库**：素材目录仅保留 55KB 高清 WebP 封面，无冗余调试图，完全符合插件提交体积规范。
- **安全数据隔离**：运行调试截图均存放在插件专属数据目录 `plugin_data/deadly_assault/`，绝不污染主仓库。

## 插件配置项

| 配置项 | 类型 | 默认值 | 说明 |
| :--- | :---: | :---: | :--- |
| `auto_team` | `bool` | `True` | 是否在挑战前自动执行智能推荐配队（步骤 6-12） |
| `wait_generate_seconds` | `int` | `300` | 点击生成更多后的最大等待时间（秒，步骤 9） |
| `walk_duration` | `float` | `5.0` | 进入战斗后向前移动的最大时间（秒，步骤 15/19/23，检测到血条提前停止） |
| `claim_rewards` | `bool` | `True` | 3 关挑战完成后是否领取荣誉酬赏（步骤 26-28） |
| `auto_battle_config` | `str` | `""` | 指定战斗策略名称，留空则跟随全局战斗助手配置 |

## 安装与使用

1. 将本目录放置在 `D:\Tools\zzz\Onedragon\plugins\deadly_assault`。
2. 启动或刷新 OneDragon，系统将自动加载并注册「危局强袭战」。
3. 在「一条龙」列表或「应用运行」页面中选择「危局强袭战」运行即可。
